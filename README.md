# Control de Contrato — Reemplazo de Cicloconvertidores Molino SAG

- `sitio/` — lo que se publica en Netlify: `index.html` (la app completa) y `simuladores/` (3 simuladores 3D).
- `fuente/` — código fuente por partes (part1.html + part*.js) y scripts `build.sh` / `publicar.sh` que arman `sitio/index.html`.

Cada cambio en la rama `main` se despliega automáticamente en Netlify (carpeta `sitio`).
